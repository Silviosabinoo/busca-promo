BUSCA PROMO 2.0 — COMPARAÇÃO SIMPLIFICADA

COMO ATUALIZAR
1. Faça backup do repositório atual, se desejar.
2. Extraia este ZIP no computador.
3. Envie os arquivos que estão dentro da pasta para a raiz do repositório GitHub.
4. Confirme a substituição dos arquivos existentes e faça Commit changes.
5. Aguarde o GitHub Pages atualizar. Se o navegador mostrar a versão antiga, faça uma atualização forçada (Ctrl+F5) ou limpe os dados/cache do site.

O QUE ESTA VERSÃO FAZ
- Prepara pesquisas do mesmo produto em várias lojas.
- Permite selecionar as lojas que deseja consultar.
- Abre links individuais para você comparar os resultados.
- Mantém uma lista de desejos local no navegador.
- Solicita permissão para notificações locais.
- Funciona como PWA instalável quando hospedada por HTTPS.

LIMITAÇÕES IMPORTANTES
- Não consulta nem coleta preços automaticamente.
- Não garante que o preço máximo seja aplicado como filtro pela loja; ele é incluído no texto da pesquisa.
- Não detecta descontos reais nem monitora preços em segundo plano.
- As lojas podem mudar seus endereços e formatos de pesquisa.
- Alguns sites podem exigir login, bloquear links ou abrir em uma nova aba.
- A lista de desejos fica armazenada no navegador/dispositivo e não sincroniza entre aparelhos.
- Não insira senhas, tokens ou chaves secretas nos arquivos públicos.

Para comparar, confira se os resultados são do mesmo modelo e considere frete, vendedor, prazo e condições de pagamento.
