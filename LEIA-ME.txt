BUSCA PROMO 2.2 — TESTE DE BUSCA AUTOMÁTICA NO MERCADO LIVRE

ATUALIZAÇÃO
1. Faça uma cópia de segurança do repositório atual.
2. Extraia este ZIP.
3. Envie os arquivos que estão dentro da pasta para a raiz do repositório GitHub.
4. Substitua os arquivos existentes e confirme o Commit changes.
5. Aguarde o GitHub Pages atualizar e abra o site com Ctrl+F5.

NOVIDADE
- Ao pesquisar um produto, o site tenta consultar a API de busca do Mercado Livre (site MLB).
- Os anúncios recebidos são exibidos em ordem crescente pelo preço anunciado.
- Cada anúncio tem link para abrir a página do Mercado Livre.
- A comparação manual, lista de desejos e links para as outras lojas continuam no site.

LIMITAÇÕES IMPORTANTES
- Esta é uma integração experimental diretamente no navegador, sem servidor.
- O Mercado Livre pode exigir autenticação, limitar ou bloquear chamadas do navegador (CORS). Se isso acontecer, o site mostrará uma mensagem e os links normais continuarão disponíveis.
- A ordenação usa o preço anunciado, não o custo final. O frete pode não estar disponível na resposta da busca e deve ser conferido no anúncio.
- Os resultados são anúncios, não confirmação de estoque/preço final.
- Não adicionamos tokens, senhas ou chaves secretas ao código público.
